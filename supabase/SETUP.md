# ตั้งค่า Supabase สำหรับระบบขอเบิกใช้งบประมาณ

ทำครั้งเดียว ใช้เวลาประมาณ 15 นาที

## 1. สร้างโปรเจกต์
1. เข้า <https://supabase.com/dashboard> → **New project**
2. ตั้งชื่อ เลือก Region (แนะนำ **Southeast Asia (Singapore)**) และตั้งรหัสผ่านฐานข้อมูล (เก็บไว้ ไม่ต้องให้ใคร)

## 2. ปิดการสมัครเอง (ให้ผู้ดูแลสร้างบัญชีให้เท่านั้น)
**Authentication → Sign In / Providers → Email**
- เปิด Email provider ไว้
- **ปิด** "Allow new users to sign up"
- (แนะนำ) ปิด "Confirm email" เพราะผู้ดูแลเป็นคนสร้างบัญชีให้ หรือติ๊ก "Auto Confirm User" ตอนสร้างผู้ใช้

## 3. สร้างตารางและฟังก์ชัน
**SQL Editor → New query** → วางเนื้อหาไฟล์ [`schema.sql`](schema.sql) ทั้งไฟล์ → **Run**
(รันซ้ำได้ ไม่ลบข้อมูล ใช้ตอนอัปเดตเวอร์ชันฐานข้อมูลในอนาคต)

## 4. สร้างผู้ใช้คนแรก (ผู้ดูแล = ฝ่ายการเงิน)
1. **Authentication → Users → Add user → Create new user** ใส่อีเมล + รหัสผ่าน (ติ๊ก Auto Confirm User)
2. กลับไป SQL Editor แล้วรัน (แก้อีเมลและชื่อ):
   ```sql
   update public.profiles set role = 'finance', name = 'ชื่อ นามสกุล', title = 'ตำแหน่ง'
   where email = 'อีเมลที่สร้างไว้';
   ```

## 5. เพิ่มผู้ใช้คนอื่น
สร้างบัญชีที่ **Authentication → Users → Add user** เหมือนข้อ 4 แล้วให้ผู้ใช้การเงินเข้าเว็บ →
เมนู **ข้อมูลหลัก → ผู้ใช้และบทบาท** เพื่อกำหนดชื่อ ตำแหน่ง และบทบาท (ผู้ขอใช้งบ / การเงิน / บัญชี)
ผู้ใช้ที่ยังไม่ได้รับบทบาทจะล็อกอินได้แต่เข้าข้อมูลไม่ได้ (เห็นหน้า "รอผู้ดูแลกำหนดสิทธิ์")

## 6. เชื่อมเว็บกับโปรเจกต์
**Project Settings → API** คัดลอก 2 ค่า:
- **Project URL** (เช่น `https://xxxx.supabase.co`)
- **anon public key** (ค่านี้เปิดเผยในหน้าเว็บได้ ความปลอดภัยอยู่ที่ฟังก์ชันและสิทธิ์ในฐานข้อมูล)

> ⚠️ **ห้ามนำ `service_role` key ไปใส่ในเว็บหรือส่งให้ใคร** — key นั้นข้ามระบบสิทธิ์ทั้งหมด

นำสองค่านั้นใส่ใน [`js/config.js`](../js/config.js):
```js
window.PROCUREMENT_CONFIG = Object.assign({
  supabaseUrl: 'https://xxxx.supabase.co',
  supabaseAnonKey: 'eyJ...'
}, window.PROCUREMENT_CONFIG || {});
```
เมื่อใส่ค่าแล้ว เว็บจะเปลี่ยนจากโหมดทดลองเป็นโหมดล็อกอินจริงทันที (เปลี่ยนเลขเวอร์ชันใน `index.html` ตามขั้นตอนขึ้นเว็บเพื่อให้เบราว์เซอร์โหลดใหม่)

## ความปลอดภัยโดยสรุป
- ตารางทุกตารางปิดการเข้าถึงโดยตรง (RLS เปิด ไม่มี policy และถอนสิทธิ์) — เบราว์เซอร์ทำได้เฉพาะเรียกฟังก์ชัน `app_*`
- ทุกฟังก์ชันตรวจ **ตัวตน + บทบาท + สถานะของเอกสาร** ฝั่งเซิร์ฟเวอร์ เช่น ผู้ขอเห็นเฉพาะงบของตน, มีแต่การเงินที่อนุมัติได้, มีแต่บัญชีที่ลงวันที่จ่ายได้
- เลขที่คำขอ/ใบเบิกออกจากฐานข้อมูล (ไม่ซ้ำแม้หลายคนใช้พร้อมกัน), การเงินแก้งบพร้อมกันจะถูกแจ้งให้โหลดใหม่
- ยอดเงินของบรรทัดคำนวณซ้ำฝั่งเซิร์ฟเวอร์ และ CAPEX เบิกเกินวงเงินรายการย่อยไม่ได้

## ข้อจำกัดที่ควรรู้
- แพ็กเกจฟรีของ Supabase จะพักโปรเจกต์ (pause) เมื่อไม่มีการใช้งานนาน — ถ้าใช้งานจริงควรใช้แพ็กเกจที่เหมาะสมและตั้งการสำรองข้อมูล
- ยังไม่มีหน้าลืม/เปลี่ยนรหัสผ่านในเว็บ ให้ผู้ดูแลตั้งรหัสใหม่ที่ Authentication → Users
