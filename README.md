# ProcurementSystem

## โมดูลขอใช้งบประมาณ (ต้นแบบ)

เปิดใช้งานได้ที่ `index.html` (รองรับ GitHub Pages โดยไม่ต้องมี backend) — หน้าทดสอบเดิมย้ายไปที่ `test.html`

ใช้เมนู **"เข้าใช้งานในฐานะ"** มุมขวาบนเพื่อสลับผู้ใช้ตัวอย่างตามบทบาท

| บทบาท | ทำอะไรได้ |
| --- | --- |
| การเงิน | บันทึก/แก้ไขงบลงทุน (CAPEX) และงบโครงการ (CBS) ที่ได้รับอนุมัติแล้ว, ตรวจสอบและยืนยันงบเป็นขั้นสุดท้าย |
| ผู้ขอใช้งบ | เห็นเฉพาะงบของตนเองพร้อมยอด *งบที่ได้รับ / อนุมัติใช้แล้ว / รออนุมัติ / คงเหลือ* และยื่นคำขอใช้งบทุกครั้งที่จะใช้ |
| ผู้จัดการฝ่าย / ผู้จัดการโครงการ | อนุมัติขั้นแรกของงบที่ตนรับผิดชอบ |
| กรรมการผู้จัดการ | อนุมัติคำขอ CAPEX ที่เกิน 1,000,000 บาท |

### กระบวนการตามประเภทงบ

**งบลงทุน (CAPEX)** — งบเป็นวงเงินก้อนเดียว
- คำขอต้องระบุ: สินทรัพย์, จำนวน, อายุการใช้งาน, เลขที่ใบเสนอราคา (ถ้ามี), เหตุผลความจำเป็น
- ขั้นอนุมัติ: ผู้จัดการฝ่าย → กรรมการผู้จัดการ (เฉพาะยอด > 1,000,000 บาท) → การเงิน

**งบโครงการ (CBS — Cost Breakdown Structure)** — งบแตกเป็นรายการต้นทุน
- คำขอต้องเลือกรายการต้นทุนที่จะใช้ และระบุงาน/งวดงาน; ยอดตรวจสอบกับ *คงเหลือของรายการนั้น*
- ขั้นอนุมัติ: ผู้จัดการโครงการ → การเงิน

### กฎเรื่องยอดงบ
- คำขอที่ยื่นแล้วจะ **จองงบ** ทันที (ป้องกันการขอซ้อนเกินวงเงิน); ถูกปฏิเสธหรือยกเลิกจะคืนงบอัตโนมัติ
- การเงินแก้ไขวงเงินให้ต่ำกว่ายอดที่ใช้/จองไปแล้วไม่ได้ และลบงบที่มีคำขอแล้วไม่ได้
- การไม่อนุมัติต้องระบุเหตุผล

### เอกสารผลลัพธ์
เมื่ออนุมัติครบทุกขั้น ระบบออก **ใบอนุมัติใช้งบ** เลขที่ `CAPEX-ปี-ลำดับ` หรือ `CBS-ปี-ลำดับ`
พร้อมสรุปยอดงบก่อน/หลังใช้ และรายชื่อผู้อนุมัติ — พิมพ์หรือบันทึกเป็น PDF เพื่อแนบกับใบขอซื้อ (PR)

### ข้อจำกัดของต้นแบบ
- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ จึงไม่แชร์ข้ามเครื่อง/ผู้ใช้จริง และไม่มีการยืนยันตัวตน
- ก่อนใช้งานจริงควรมี backend + ฐานข้อมูล, ระบบล็อกอิน, และเชื่อมเลขที่ใบอนุมัติใช้งบเข้ากับขั้นตอนขอซื้อ (PR)
